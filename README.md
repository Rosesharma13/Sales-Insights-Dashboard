# Sales Insights Dashboard 📊

## Overview
End-to-end sales data analysis uncovering product performance 
trends and regional patterns for a consumer goods company.

## Tech Stack
- 🐍 Python — data preprocessing
- 📊 Tableau — interactive dashboards
- 📈 MS Excel — data handling
- 🔢 Pandas — data cleaning

## Key Insights Generated
- Top performing products by region
- Seasonal sales trends
- Inventory planning recommendations
- Marketing performance metrics

## How to Run
1. Clone the repository
   git clone https://github.com/yourusername/sales-insights-dashboard
2. Install requirements
   pip install -r requirements.txt
3. Run analysis
   python analysis.py
4. Open Tableau file for dashboard
